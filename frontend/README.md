# EditorialWeb Frontend

Современное Single Page Application (SPA) для редакционной платформы EditorialWeb на стеке **React 18 + TypeScript + Vite + Tailwind CSS**.

## Возможности

- **Полный редакционный цикл:**
  - Создание черновиков (`DRAFT`), редактирование с Markdown-панелью и живым предпросмотром
  - Отправка на рассмотрение редактором (`PENDING_REVIEW`)
  - Очередь модерации для редакторов (`EDITOR` и `ADMIN`): чтение, одобрение в публикацию (`PUBLISHED`) или отклонение (`REJECTED`) с сохранением комментария с причиной
  - Архивирование опубликованных статей (`ARCHIVED`) и возможность повторной подачи
  - Удаление статей с модальным подтверждением
- **Аутентификация и безопасность:**
  - JWT Access Token (30 минут) + Refresh Token (30 дней)
  - Прозрачный Axios-перехватчик с очередью запросов при автоматическом обновлении токена (401 Refresh)
  - Интеллектуальный вход: автоматическая обработка асинхронного создания профиля через Kafka (`ACCOUNT_STILL_PENDING`) с поллингом и спиннером
- **Матрица ролей (`USER`, `AUTHOR`, `EDITOR`, `ADMIN`):**
  - Разделение прав доступа на уровне роутера (`ProtectedRoute`) и динамическое меню навигации
  - Профиль пользователя: просмотр метаданных, редактирование отображаемого имени (`displayName`) и описания (`profileDescription`)
  - Панель администратора: управление учетными записями, смена ролей, редактирование профилей
- **Лента статей:**
  - Пагинация Spring Data `Page`
  - Фильтрация по автору
  - Детальный просмотр с форматированием Markdown

## Локальная разработка

```sh
cd frontend
npm install
npm run dev
```

Dev-сервер запускается на `http://localhost:3000` и прозрачно проксирует запросы к `/api` на шлюз `http://localhost:8080`.

## Сборка и проверка

```sh
npm run build
```

## Docker

Фронтенд контейнеризирован с использованием multi-stage build (Node Alpine → Nginx Alpine) и обслуживается на порту 3000 в `docker-compose.yaml`.
